# Day 21 — Power BI Security Dashboard

## Goal

The goal of this day was to build a Power BI dashboard based on the CSV dataset generated by the Python log analyzer.

## Dataset

`python-log-analyzer/output/security_events_for_powerbi.csv`

## Dashboard file

`powerbi-dashboard/security-authentication-dashboard.pbix`

## What I did

1. Imported the Power BI-ready CSV dataset.
2. Checked column types.
3. Created DAX measures for total events, failed logins, successful logins, unique source IPs, and unique users.
4. Built overview cards.
5. Created charts for failed logins by source IP, targeted users, risk level, and event type.
6. Added slicers for filtering.
7. Added a detailed authentication events table.
8. Saved the Power BI dashboard file.

## DAX measures

```DAX
Total Events = SUM(security_events_for_powerbi[event_count])
```

```DAX
Failed SSH Logins =
CALCULATE(
    [Total Events],
    security_events_for_powerbi[event_type] = "failed_ssh_login"
)
```

```DAX
Successful SSH Logins =
CALCULATE(
    [Total Events],
    security_events_for_powerbi[event_type] = "successful_ssh_login"
)
```

```DAX
Unique Source IPs = DISTINCTCOUNT(security_events_for_powerbi[src_ip])
```

```DAX
Unique Users = DISTINCTCOUNT(security_events_for_powerbi[user])
```

## Result

The project now includes a Power BI dashboard for visualizing parsed SSH authentication events.
